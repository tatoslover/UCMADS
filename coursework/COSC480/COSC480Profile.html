Project Overview

This interactive data visualization project analyzes NBA statistics from three teams (Dallas Mavericks, Los Angeles Lakers, and New York Knicks) across three time periods (2000, 2010, 2020).

The application allows users to explore relationships between key performance metrics like three-point shooting percentage, three-point attempt volume, and scoring with team success as measured by win percentage.

Through this analysis, the project reveals the evolution of NBA basketball over two decades, particularly the shift toward perimeter-oriented play and its impact on team performance.

Application Features

Interactive Data Selection

Users can select from multiple teams, seasons (regular/playoff/both), and statistics to customize the analysis.

Dynamic Visualization

The application generates scatter plots showing relationships between selected statistics and win percentages.

Data Export

Automatically saves visualizations as high-resolution PNG files and exports data to CSV for further analysis.

Statistical Summary

Provides detailed statistical analysis including averages and changes over time.

User-Friendly Interface

Intuitive command-line interface with clear prompts and robust error handling.

Time-Series Analysis

Visualizes trends across three distinct time periods (2000, 2010, 2020) to show evolution.

How to Run the Application

  1. Navigate to the project directory: cd /path/to/COSC480/
  2. Ensure Python and dependencies are installed: pip install numpy matplotlib pandas
  3. Run the enhanced code: python ProjectCode_Enhanced.py
  4. Follow the interactive prompts to select a team, season type, and statistic
  5. View the generated visualization and summary statistics in the console
  6. Find exported files (PNG visualizations and CSV data) in the same directory
